Tracking Spending

A bank export tells you every dollar that left your account, but it doesn’t tell you where your money went. To answer that, each transaction needs a category, and the small recurring charges need a second look. The Tracking Spending chapter of the book covers both questions. In this page I’ll answer them with two perfinpy functions. apply_rules() sorts transactions into buckets. subscription_opportunity_cost() shows what a subscription would have grown to if you had invested the money instead.

Function Returns Units
apply_rules() the transactions with a Category column added text categories; "Other" when nothing matches
subscription_opportunity_cost() what the yearly cost grows to if invested dollars; rate is a decimal (0.07 is 7%)

Where did the money go?

The statement has 17 transactions and no Category column. To add one, we map each description to a bucket with a lookup table of keyword patterns. Each Pattern is a regular expression (a text search pattern), so | means “or” and one rule can cover several merchants:

rules = pl.DataFrame({
    "Pattern": ["Payroll", "Rent", "Comcast|PG&E|AT&T",
                "Trader Joe|Whole Foods|Costco", "Shell",
                "Starbucks|Chipotle",
                "Netflix|Spotify|NYTimes|24 Hour Fitness", "Geico"],
    "Category": ["Income", "Housing", "Utilities", "Groceries",
                 "Transportation", "Dining", "Subscriptions", "Insurance"],
})

apply_rules() checks the 8 rules in order against each description and keeps the first match. The table below shows each transaction next to the bucket it landed in:

categorized = apply_rules(df=bank_statement, rules=rules)

When a transaction doesn’t match

New merchants show up every month. The book’s rule is “when in doubt, Other.” A transaction that matches no pattern lands in "Other" until you’ve seen it often enough to deserve its own rule. The code below runs two new transactions through the same rules:

new_transactions = pl.DataFrame({
    "Description": ["Venmo Payment", "SPOTIFY FAMILY PLAN"],
})
apply_rules(df=new_transactions, rules=rules)
shape: (2, 2)
DescriptionCategory

"Venmo Payment""Other"
"SPOTIFY FAMILY PLAN""Subscriptions"

The Venmo payment falls through to "Other". The Spotify charge still lands in "Subscriptions" because apply_rules() ignores case, so "Spotify" matches "SPOTIFY".

What does a subscription really cost?

A subscription’s real cost is its opportunity cost: the money you give up by spending instead of investing. The book’s example is a monthly subscription you don’t really use, with the money invested instead at a real return (the return after inflation). The code below stores the book’s inputs:

monthly_cost = 20
years = 30
rate = 0.07

Canceling the $20 a month subscription frees up $240 a year to invest at 7% for 30 years. The chart below shows what that money grows into at each checkpoint, split into the money you put in and the growth it earned.

Each bar adds another year’s deposit to everything saved so far, and the whole pile grows by 7%. subscription_opportunity_cost() adds up every year’s deposit and its growth in one step:

sub_cost = subscription_opportunity_cost(
    monthly_cost=monthly_cost,
    years=years,
    rate=rate,
)
sub_cost
22670.58871769843

Over 30 years you put in $7,200, and growth adds $15,471 on top of it. That “small” $20 a month is a $22,671 decision.

Comparing horizons

subscription_opportunity_cost() accepts arrays, so one call can fill in every bar of the chart above. The code below puts the five checkpoints in a pl.DataFrame with the money put in and the growth:

checkpoints = [1, 5, 10, 20, 30]
horizons = pl.DataFrame({
    "years": checkpoints,
    "put_in": [monthly_cost * 12 * y for y in checkpoints],
    "value": subscription_opportunity_cost(monthly_cost, checkpoints, rate).round(2),
}).with_columns(growth=pl.col("value") - pl.col("put_in"))

WarningLimits
  • apply_rules(): the first matching rule wins, so put specific patterns above general ones. Patterns are regular expressions with case ignored, so characters like ., +, and ( have special meanings. The function only reads Description; a Netflix refund lands in "Subscriptions" just like the charge. An existing Category column is replaced. Both arguments must be polars DataFrames.
  • subscription_opportunity_cost(): it invests the yearly total once, at the end of each year, at one fixed rate. The book’s $267,000 figure for $219 a month assumes monthly deposits, so it comes out higher than this function’s result for the same inputs. The 7% default is a real return, so the result is in today’s dollars. It does not reject negative costs.

Putting it together

The book’s monthly review ends with a subscription audit: list every recurring charge and decide whether it’s worth the cost. The categorized statement already holds that list. The code below pulls the subscription rows and prices each one over the same horizon:

subs = categorized.filter(pl.col("Category") == "Subscriptions")
monthly = -subs["Amount"]
audit = pl.DataFrame({
    "Description": subs["Description"],
    "monthly": monthly,
    "cost_30": subscription_opportunity_cost(monthly.to_numpy(), years=years).round(2),
})

These 4 subscriptions cost $83.97 a month, which adds up to $95,182 over 30 years. To put the monthly total in context, percent_of_income() from the Budgeting page compares it with the paycheck on the statement:

paycheck = categorized.filter(pl.col("Category") == "Income")["Amount"][0]
subs_share = percent_of_income(expense=audit["monthly"].sum(), income=paycheck)
subs_share

Subscriptions take about 3.5% of the paycheck. As in the rest of perfinpy, the ratio comes out as a percent, not a decimal (see the conventions in Get started). The gym membership alone accounts for $45,330 of the 30 year total. That makes it the first one to check against the book’s audit question: have you used it in the last 30 days?

Recap

apply_rules() turns a bank export into categorized spending with a small, stable table of keyword patterns, and anything new falls through to "Other". subscription_opportunity_cost() puts a price on recurring charges by showing what the money would grow to if invested. Together they cover the recording side of personal finance, which feeds the allocation decisions in Budgeting.
